# Vietnam Export Analysis (1997 - 2020) 📈🇻🇳

## 📌 Project Overview
This project analyzes the historical growth and structural transformation of Vietnam's merchandise exports from 1997 to 2020. It evaluates key trading partners, commodity shifts, and macroeconomic impacts across major Free Trade Agreement (FTA) milestones.

## 🎯 Key Business Questions & Scope
- Which export markets have driven the majority of Vietnam's trade surplus over the two decades?
- How did key milestones (e.g., WTO accession, bilateral/multilateral FTAs) reshape Vietnam's export basket?
- Shifts from raw agricultural commodities to high-tech manufacturing and electronics.
